# Character Sheet Definitions

Name: The name of the person playing the character

Guise: The name of the character

Vision: Normal, Infrasion in feet (XX'), Ultravision

Handed: Right, Left or Ambi

Luck: House rule. d20 at birth, drops from there

Hit points gained: At each level, write down the new total

|NWP      |                                                |
|---------|------------------------------------------------|
| Number  | The base number at start                       |
| gained  | One slot gained every X levels                 |  
| Skill   | The NWP name                                   | 
| Ability | What to roll against Str,Int,Wis... for sucess |
| Mod     | applied to ability                             |

Skills & Detection: Abilities that are gained by class, like paladin's 'Lay on
Hands' or ranger's 'animal empathy'.

Missiles & #of: Arrows, javlins, daggers, etc and how many (the count possessed)
