# NPC Sheet Transcription Rules

## Core Principle
**Transcribe, don't redesign.** Use existing fields, preserve the template, and avoid duplication.

## Formatting
- Put values immediately after colons: `STR:17`
- Do not add, remove, rename, or reorder sections.
- Leave unknown values blank.
- Keep tables aligned for plain-text readability.

## AC
**`AC:`** is the front armor class, `Rear:` = front ac - shield - DEX bonus.

## Surprise
describe surprise and surprised as: `1/10, 2/10`
## Weapons

- Melee Weapons go only in the Weapon table.
- Ranged Weapons go only in the Ranged table. Arrow and bullet count go under Count.

## Skills
- Non-weapon proficiencies go only in the Skill table.
- Notes should be short and preferably mechanical.

## Armor
- Armor and shield belong only in: `Armor Worn:`

## Coins
Coins belong only in:

```text
pp:    gp:    ep:    sp:    cp:
```

## Spells/Powers
Include only:
- Spells
- Spell-like abilities
- Innate powers
- Class abilities


## Inventory
Only items not represented elsewhere.
- Ammunition
- Rations
- Clothing
- Jewelry
- Tools
- Miscellaneous gear

## Senses/Detections
Include only sensory abilities such as:
- Normal Sight
- Infravision
- Detect Evil

## Miscellaneous
Use for anything without a dedicated field:
- Age
- Height
- Weight
- Hair
- Eyes
- Appearance
- Mannerisms
- Experience
- Character notes

## Redundancy Rule
Every piece of information should appear **once and only once**.
